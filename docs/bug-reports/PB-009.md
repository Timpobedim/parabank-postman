# PB-009. Перевод с пустой суммой — внутренняя ошибка 500 вместо 400

| Поле | Значение |
|---|---|
| Серьёзность | Minor |
| Приоритет | Medium |
| Окружение | parasoft/parabank (digest `sha256:747453a0…`), http://localhost:8090/parabank · 11.10.2026 |
| Воспроизводимость | стабильно |
| Проверки | `collections/known-defects.postman_collection.json` → «PB-009 пустая сумма»<br>`collections/transfer-boundaries.postman_collection.json` + `data/transfer-amounts.csv` → «пустая сумма» |

## Шаги

1. `POST /services/bank/transfer?fromAccountId=<A>&toAccountId=<B>&amount=`.

## Ожидаемый результат

400 с указанием, что сумма обязательна.

## Фактический результат

`500`, `Content-Type: text/html;charset=ISO-8859-1` — HTML-страница ошибки сайта. Остаток не меняется.

## Примечание

В интерфейсе описан в [parabank-ui-api](https://github.com/Timpobedim/parabank-ui-api/blob/main/docs/bug-reports/PB-009.md); здесь — то же через REST API.
