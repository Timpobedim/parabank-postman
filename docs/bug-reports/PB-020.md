# PB-020. Перевод на ноль проходит

| Поле | Значение |
|---|---|
| Серьёзность | Trivial — в истории появляются операции на $0 |
| Приоритет | Low |
| Окружение | parasoft/parabank (digest `sha256:747453a0…`), http://localhost:8090/parabank · 11.10.2026 |
| Воспроизводимость | стабильно |
| Проверки | `collections/known-defects.postman_collection.json` → «PB-020 перевод на ноль»<br>`collections/transfer-boundaries.postman_collection.json` + `data/transfer-amounts.csv` → «ноль» |

## Шаги

1. `POST /services/bank/transfer?fromAccountId=<A>&toAccountId=<B>&amount=0`.

## Ожидаемый результат

400: сумма должна быть больше нуля.

## Фактический результат

`200 Successfully transferred $0 …`; в истории обоих счетов — операции на $0.00.

## Примечание

Остатки не меняются, поэтому в наборе граничных значений проверка «остаток не изменился» для этого случая проходит — помечена только проверка кода ответа.
