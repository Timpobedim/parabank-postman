# PB-005. Текстовый ответ объявлен как JSON или XML

| Поле | Значение |
|---|---|
| Серьёзность | Minor — клиент, который разбирает ответ по Content-Type, падает на разборе |
| Приоритет | Low |
| Окружение | parasoft/parabank (digest `sha256:747453a0…`), http://localhost:8090/parabank · 11.10.2026 |
| Воспроизводимость | стабильно |
| Проверки | `collections/known-defects.postman_collection.json` → «PB-005 тип ответа перевода» |

## Шаги

1. `POST /services/bank/transfer?...&amount=1` с `Accept: application/json`.
2. Тот же запрос без заголовка `Accept`.

## Ожидаемый результат

`Content-Type: text/plain` — тело `Successfully transferred …` не JSON и не XML.

## Фактический результат

С `Accept: application/json` — `Content-Type: application/json`; без `Accept` — `application/xml`. Тело в обоих случаях — обычная строка.

## Примечание

Впервые — [parabank-ui-api](https://github.com/Timpobedim/parabank-ui-api/blob/main/docs/bug-reports/PB-005.md). Новое здесь: без `Accept` тот же текст объявлен как XML — видно в журнале `pbqa proxy`. То же у `deposit` и `withdraw`.
