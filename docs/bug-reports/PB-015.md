# PB-015. SOAP-перевод без суммы — soap:Server с текстом NullPointerException

| Поле | Значение |
|---|---|
| Серьёзность | Minor — клиенту видна внутренняя ошибка, а не причина |
| Приоритет | Medium |
| Окружение | parasoft/parabank (digest `sha256:747453a0…`), http://localhost:8090/parabank · 11.10.2026 |
| Воспроизводимость | стабильно |
| Проверки | `collections/known-defects.postman_collection.json` → «PB-015 перевод без суммы — SOAP» |

## Шаги

1. SOAP `transfer` с `fromAccountId` и `toAccountId`, но без элемента `amount`.

## Ожидаемый результат

Fault `soap:Client` «amount обязателен» — элемент в WSDL не помечен `minOccurs="0"`.

## Фактический результат

Fault `soap:Server`: `Cannot read field "intCompact" because "<parameter1>" is null` — сообщение NullPointerException: сервис обращается к полю `BigDecimal` пустой суммы.

## Примечание

Нечисловая сумма, наоборот, разбирается правильно: `1,5` — `soap:Client` «Unmarshalling Error».
