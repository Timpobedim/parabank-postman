# PB-008. Отказ в кредите возвращает ключ локализации вместо текста

| Поле | Значение |
|---|---|
| Серьёзность | Trivial |
| Приоритет | Low |
| Окружение | parasoft/parabank (digest `sha256:747453a0…`), http://localhost:8090/parabank · 11.10.2026 |
| Воспроизводимость | стабильно |
| Проверки | `collections/known-defects.postman_collection.json` → «PB-008 отказ в кредите» |

## Шаги

1. `POST /services/bank/requestLoan?customerId=<id>&amount=1000000&downPayment=10&fromAccountId=<A>`.

## Ожидаемый результат

`message` — понятная причина отказа.

## Фактический результат

`"approved":false,"message":"error.insufficient.funds"`. В SOAP — тот же ключ в `<message>`.
