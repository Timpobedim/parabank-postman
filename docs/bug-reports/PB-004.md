# PB-004. Несуществующий счёт — 400 вместо 404

| Поле | Значение |
|---|---|
| Серьёзность | Minor — клиент API не отличит «нет такого счёта» от «неверный запрос» |
| Приоритет | Low |
| Окружение | parasoft/parabank (digest `sha256:747453a0…`), http://localhost:8090/parabank · 11.10.2026 |
| Воспроизводимость | стабильно |
| Проверки | `collections/known-defects.postman_collection.json` → «PB-004 несуществующий счёт» |

## Шаги

1. `GET /services/bank/accounts/1`.

## Ожидаемый результат

404.

## Фактический результат

`400 Could not find account #1`.

## Примечание

Впервые — [parabank-ui-api](https://github.com/Timpobedim/parabank-ui-api/blob/main/docs/bug-reports/PB-004.md). В SOAP та же ситуация приходит Fault-ом `soap:Server` — см. PB-017.
