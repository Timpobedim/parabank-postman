# PB-019. Нечисловая сумма перевода — 404 с пустым телом

| Поле | Значение |
|---|---|
| Серьёзность | Minor — 404 означает «нет такого ресурса», клиент ищет ошибку в адресе |
| Приоритет | Low |
| Окружение | parasoft/parabank (digest `sha256:747453a0…`), http://localhost:8090/parabank · 11.10.2026 |
| Воспроизводимость | стабильно |
| Проверки | `collections/known-defects.postman_collection.json` → «PB-019 сумма не число»<br>`collections/transfer-boundaries.postman_collection.json` + `data/transfer-amounts.csv` → «запятая вместо точки», «не число» |

## Шаги

1. `POST /services/bank/transfer?fromAccountId=<A>&toAccountId=<B>&amount=abc`.
2. То же с `amount=1,5`.

## Ожидаемый результат

400 с указанием поля `amount`.

## Фактический результат

`404`, тело пустое. Остаток не меняется.

## Примечание

Пустая сумма даёт 500 (PB-009), нечисловая — 404, отрицательная — 200 (PB-002): у одного поля три разных реакции на неверное значение.
