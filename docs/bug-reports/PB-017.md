# PB-017. SOAP: ошибки клиента возвращаются как soap:Server

| Поле | Значение |
|---|---|
| Серьёзность | Minor — клиент считает ошибку временной и повторяет запрос, который не пройдёт никогда |
| Приоритет | Low |
| Окружение | parasoft/parabank (digest `sha256:747453a0…`), http://localhost:8090/parabank · 11.10.2026 |
| Воспроизводимость | стабильно |
| Проверки | `collections/known-defects.postman_collection.json` → «PB-017 неверный пароль — SOAP» |

## Шаги

1. SOAP `login` с неверным паролем.
2. SOAP `getAccount(accountId=1)`.

## Ожидаемый результат

Fault `soap:Client`: причина в запросе (SOAP 1.1, раздел 4.4.1).

## Фактический результат

Fault `soap:Server` «Invalid username and/or password» и «Could not find account #1» с `ParaBankServiceException` в `detail`.

## Примечание

REST на те же запросы отвечает 400, то есть сервис сам считает это ошибкой клиента.
