# PB-001. Перевод больше остатка проходит — и через REST, и через SOAP

| Поле | Значение |
|---|---|
| Серьёзность | Critical — остаток уходит в минус без кредитного лимита |
| Приоритет | High |
| Окружение | parasoft/parabank (digest `sha256:747453a0…`), http://localhost:8090/parabank · 11.10.2026 |
| Воспроизводимость | стабильно |
| Проверки | `collections/known-defects.postman_collection.json` → «PB-001 перевод больше остатка», «PB-001 перевод больше остатка — SOAP»<br>`collections/transfer-boundaries.postman_collection.json` + `data/transfer-amounts.csv` → «остаток плюс цент», «сумма больше остатка» |

## Шаги

1. Новый клиент, два счёта: A ($415.50) и B ($100) — см. папку «0. Новый клиент».
2. `POST /services/bank/transfer?fromAccountId=<B>&toAccountId=<A>&amount=100000`.
3. То же через SOAP: `transfer(fromAccountId=B, toAccountId=A, amount=100000)`.

## Ожидаемый результат

REST — 400, SOAP — Fault `soap:Client`: на счёте недостаточно средств. Остаток не меняется.

## Фактический результат

REST: `200 Successfully transferred $100000 from account #B to account #A`. SOAP: `transferReturn` с тем же текстом. Остаток B становится −$99 900.

## Примечание

Граница проверена точно: перевод `остаток + $0.01` тоже проходит. Через REST дефект впервые описан в [parabank-ui-api](https://github.com/Timpobedim/parabank-ui-api/blob/main/docs/bug-reports/PB-001.md); здесь добавлено, что SOAP-интерфейс ведёт себя так же.
