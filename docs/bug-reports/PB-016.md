# PB-016. Неизвестный тип счёта — 500 и текст исключения ArrayIndexOutOfBounds

| Поле | Значение |
|---|---|
| Серьёзность | Minor — внутренняя ошибка вместо отказа; в SOAP клиенту показан текст исключения |
| Приоритет | Medium |
| Окружение | parasoft/parabank (digest `sha256:747453a0…`), http://localhost:8090/parabank · 11.10.2026 |
| Воспроизводимость | стабильно |
| Проверки | `collections/known-defects.postman_collection.json` → «PB-016 неизвестный тип счёта — REST», «PB-016 неизвестный тип счёта — SOAP» |

## Шаги

1. `POST /services/bank/createAccount?customerId=<id>&newAccountType=7&fromAccountId=<A>`.
2. SOAP `createAccount` с `newAccountType=7`.

## Ожидаемый результат

REST — 400, SOAP — Fault `soap:Client`: допустимые типы 0, 1, 2.

## Фактический результат

REST — `500`, HTML-страница ошибки. SOAP — Fault `soap:Server` «Index 7 out of bounds for length 3».

## Примечание

Судя по тексту исключения, тип счёта приходит числом и используется как индекс массива без проверки.
