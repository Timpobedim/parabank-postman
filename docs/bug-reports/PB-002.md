# PB-002. Перевод на отрицательную сумму проходит — деньги идут в обратную сторону

| Поле | Значение |
|---|---|
| Серьёзность | Critical — можно списать деньги со счёта, указав его как получателя |
| Приоритет | High |
| Окружение | parasoft/parabank (digest `sha256:747453a0…`), http://localhost:8090/parabank · 11.10.2026 |
| Воспроизводимость | стабильно |
| Проверки | `collections/known-defects.postman_collection.json` → «PB-002 отрицательный перевод», «PB-002 отрицательный перевод — SOAP»<br>`collections/transfer-boundaries.postman_collection.json` + `data/transfer-amounts.csv` → «минус цент» |

## Шаги

1. Клиент с двумя счетами A и B.
2. `POST /services/bank/transfer?fromAccountId=<A>&toAccountId=<B>&amount=-10` — и то же через SOAP.

## Ожидаемый результат

400 / Fault `soap:Client`: сумма должна быть положительной.

## Фактический результат

`200 Successfully transferred $-10 from account #A to account #B`: B уменьшается, A растёт. SOAP — так же.
